# Optional fonts

The dashboard asks for **Thmanyya** first and falls back to Dubai, Inter, then
the system UI font. Nothing is downloaded at runtime — the page must work with
no network.

To use Thmanyya, either install it on the machine, or drop these files here:

```text
Thmanyya-Regular.woff2
Thmanyya-Bold.woff2
```

They are deliberately not committed: the typeface is not ours to redistribute.
Check its licence before adding the files to the repository.
